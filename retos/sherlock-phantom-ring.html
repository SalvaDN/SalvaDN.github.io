PhantomRing - Sherlock

Fecha: 23 sep 2026 Dificultad: Medium Categoría: DFIR / Reverse Engineering Sistema: Linux Plataforma: HackTheBox

Resumen

Análisis estático y de ingeniería inversa de un binario en Linux. Comprobamos la entropía para descartar que esté empaquetado, extraemos cadenas de texto relevantes y examinamos el uso de la interfaz de E/S asíncrona de alto rendimiento io_uring junto con diversas rutas y rutinas internas del sistema.

Escenario

Investigación de un binario sospechoso en un entorno Linux. El flujo de análisis comprende la verificación estructural, revisión de entropía, extracción de strings y resolución de las tareas técnicas del reto.

Artefactos y herramientas

  • Artefactos: Binario analizado del reto PhantomRing.
  • Herramientas: Analizadores de entropía, herramientas de extracción de strings e ingeniería inversa.

Análisis

Reconocimiento inicial y Entropía

Realizamos una inspección preliminar del binario y comprobamos sus niveles de entropía, confirmando que no se encuentra empaquetado.

Extraemos las cadenas de texto (strings) incrustadas para localizar referencias clave.

Tarea 1

Pregunta: What is the SHA-256 hash / identifier of the analyzed binary?

Respuesta: 2d7b1b2178f76c26893b2a56cbf9b36700235259e76b893d53817d5b66b634a5

Tarea 2

Pregunta: What is the IP address hardcoded in the binary for C2 communication?

Respuesta: 192.168.56.1

Tarea 3

Pregunta:What port does the agent connect to on the C2 server?

Respuesta: 4445

Tarea 4

Pregunta: How many seconds does the agent wait before attempting to reconnect after a failed connection?

Respuesta: 120

Tarea 5

Pregunta: How many different commands does the agent support? (excluding invalid commands)

Respuesta: 11

Tarea 6

Pregunta: What is the high-performance asynchronous I/O interface utilized by the malware?

El binario hace uso de la interfaz de E/S asíncrona de alto rendimiento de Linux llamada io_uring.

Respuesta: io_uring

Tarea 7

Pregunta: What system file or accounting record path is targeted by the binary?

Respuesta: /var/run/utmp

Tarea 8

Pregunta: What directory path is referenced for binaries or commands?

Respuesta: /usr/bin

Tarea 9

Pregunta:What string does the agent search for in /proc/[pid]/maps to identify security tools using eBPF?

Respuesta: anon_inode:bpf-map

Tarea 10

Pregunta:What is the full path of the first tracing file the agent attempts to disable?

Respuesta: /sys/kernel/debug/tracing/tracing_on

Tarea 11

Pregunta:What procfs path does the agent read to find its own executable location before self-destruction?

Respuesta: /proc/self/exe

Tarea 12

Pregunta: What specific destruction or cleanup function/routine name is identified?

Respuesta: sdestruct

Indicadores de compromiso (IOC)

  • Hash del binario: 2d7b1b2178f76c26893b2a56cbf9b36700235259e76b893d53817d5b66b634a5
  • Interfaz de E/S utilizada: io_uring
  • Rutas objetivo: /var/run/utmp, /usr/bin
  • Rutinas clave: sdestruct

Conclusiones

El análisis del binario PhantomRing demuestra el uso de características avanzadas de Linux como la interfaz de E/S asíncrona io_uring para la ejecución eficiente y sigilosa de operaciones, integrando rutinas de limpieza como sdestruct para la eliminación de huellas.
